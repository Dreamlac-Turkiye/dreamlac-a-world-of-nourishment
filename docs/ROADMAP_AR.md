# خارطة بناء منظومة Dreamlac التجارية

هذه الوثيقة هي المرجع التنفيذي الثابت للمشروع. يُستخدم Lovable لمعاينة الواجهات فقط، بينما يبقى الكود وقاعدة البيانات ومنطق الأعمال والاستضافة قابلين للنقل ومستقلين عنه.

## مبادئ لا تتغير

- تركيا هي السوق الأول (`TR`) والدومين المستهدف `dreamlac.com.tr`.
- المنتجات الأولى: Dreamlac 1 و2 و3 فقط.
- كل سوق يعزل الأسعار واللغة والعملة والقانون والمخزون والتكاملات.
- لا أسرار أو مفاتيح مزودين داخل GitHub أو الواجهة.
- لا تعتمد حالة الدفع على رجوع متصفح العميل؛ المصدر الموثوق هو Webhook موثّق.
- كل عملية حساسة قابلة للتدقيق، وكل تعديل مخزون أو صلاحية مسجّل.
- حماية الصلاحيات تكون في الخادم وقاعدة البيانات، وليس بإخفاء أزرار الواجهة فقط.
- لا تفعّل المبيعات الحية قبل اعتماد الشركة والأسعار والمخزون والنصوص القانونية والمزودين.

## رحلة العميل المستهدفة

1. اكتشاف العلامة من الصفحة الرئيسية أو البحث أو الإعلان.
2. اختيار المرحلة العمرية والاطلاع على المنتج والمكونات والتحذيرات.
3. إضافة المنتج إلى السلة والتحقق من المخزون والسعر.
4. تسجيل الدخول أو المتابعة كزائر وإدخال العنوان.
5. اختيار الشحن والدفع ومراجعة الطلب والموافقة على الوثائق المعتمدة.
6. إنشاء الطلب وحجز المخزون ثم تأكيد الدفع من المزود.
7. متابعة التجهيز والشحن والفاتورة والإشعارات.
8. استخدام الحساب أو التتبع كزائر وطلب الإلغاء أو الإرجاع أو الدعم.

## الأدوار المستهدفة

- المالك: كل الأسواق والإعدادات الحساسة.
- المدير العام: المؤشرات والتنبيهات وإدارة الموظفين.
- مدير المتجر: الطلبات والمنتجات والأسعار والمخزون.
- موظف الطلبات: المراجعة والتجهيز ضمن صلاحيات محددة.
- موظف المستودع: المخزون وقوائم التجهيز والتسليم للكارجو.
- خدمة العملاء: العملاء والتذاكر والإلغاء والإرجاع.
- المحاسب: المدفوعات والاسترداد والفواتير والتقارير المالية.
- مدير المحتوى: المحتوى والمنتجات والأسئلة وSEO.
- مسؤول الامتثال: الوثائق القانونية والموافقات.
- مسؤول النظام: التكاملات والأخطاء وسجلات التشغيل.
- قارئ تقارير: قراءة فقط.
